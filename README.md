# CRUD de productos con PHP, MySQL y MVC
Aplicación web para gestionar productos (listar, buscar, registrar,
editar y eliminar), hecha con PHP, PDO y MySQL siguiendo el patrón MVC.

## Cómo usarlo
1. Importa base_datos.sql en MySQL.
2. Copia la carpeta en htdocs de XAMPP.
3. Abre http://localhost/NOMBRE_DE_LA_CARPETA/
