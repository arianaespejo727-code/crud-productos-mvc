# CRUD de Productos con PHP, MySQL y MVC

Aplicación web para gestionar un catálogo de productos. Permite listar,
buscar por código o nombre, registrar, editar y eliminar productos, con
mensajes de confirmación y validación de datos.

## Funcionalidades
- Listado de productos en tabla
- Búsqueda por código o nombre
- Registro con validación de campos y precio mayor que cero
- Edición con datos precargados
- Eliminación con confirmación (por POST)

## Tecnologías
PHP, PDO, MySQL, HTML y CSS, con el patrón MVC (Modelo, Vista, Controlador).
